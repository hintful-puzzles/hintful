## MODIFIED Requirements

### Requirement: Nothing is generated into the source tree

Nothing the build reads SHALL be generated by the build: the game catalog is
committed TypeScript source (`src/puzzle/catalog-data.ts`), the per-puzzle
icons are a committed snapshot, and the help pages are committed markdown.
There SHALL be no asset build step. A module compiled from a description
(`*.compiled.ts`) SHALL be committed beside it, and a test in the gate SHALL
compile every description again and fail where the committed module differs.

#### Scenario: No artifact is generated into the source tree

- **WHEN** the repository is inspected after a build
- **THEN** `src/assets/` holds only committed files
- **AND** `.gitignore` carries no rule for a generated directory under `src/`

#### Scenario: A description edited without compiling fails the gate

- **WHEN** a technique in a `*.description.json` is edited and
  `npm run describe` is not run
- **THEN** the gate fails, naming the description whose module is stale
