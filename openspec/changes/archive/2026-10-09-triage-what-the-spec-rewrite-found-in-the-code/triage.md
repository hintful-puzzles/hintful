# Triage of what the spec rewrite found in the code

One row for every entry of the two lists in
`openspec/changes/archive/2026-10-09-turn-the-specs-into-a-reference/rewrite-report.md`:
§ "Where the code looks wrong and the spec right" (rows `A-`) and § "Left
unresolved by a reviewer" (rows `B-`). A row's id is the list, the capability
heading it sits under and its place under that heading, counted from 1, so
`A-guess-2` is the second entry under `### guess` in the first list. The rows
are in the report's order.

The kinds are those of `proposal.md`: a duplicate of another row, a stale
comment (or stale guide or help prose), a weak guard, the spec is wrong, a
suspected defect (with who would meet it: a player, a session relying on the
gate, or nobody yet), and nothing. A suspected defect's row says whether it
was reproduced and how. Where a requirement is named, it is the one that now
carries the finding, in `openspec/specs/<capability>/spec.md`.

## What a player would have met, in the order they would meet it

Reproduced, and fixed here:

- A crash report: three events were sent where the player had agreed to one
  (`A-project-identity-1`). The owner then decided what a report carries; see
  that row.
- Signpost: Check reported a mistake and nothing was red (`A-signpost-1`).
- Flood: no line between regions on a phone-sized board (`A-flood-1`).
- Fifteen: "into place" said of a tile the plan moves again (`A-fifteen-1`).
- Galaxies and Bridges: a canceled press removed an arrow or drew a bridge
  (`A-galaxies-4`). The cause is in the shared view, which reports a cancel
  as a drag far off the board, and a survey flagged ten more games; that is a
  change of its own, taken up after this one.
- Boats: a fleet drawn past the canvas (`A-boats-1`, `A-boats-2`).
- Range: a pasted board with several answers, on which Check called a correct
  square a mistake (`A-range-1`).
- Sokoban: Solve threw on a level with a lettered barrel (`A-sokoban-1`).
- Seismic and Salad: an entry that changed nothing made an undo step
  (`A-seismic-1`, `A-salad-2`); Salad's rare shape that ran its retry bound
  out (`A-salad-1`).
- Spokes: erasing a line cleared the player's own mark (`A-spokes-1`).
- Guess: the cursor left on Submit in notes mode (`A-guess-2`).
- Filling's frame weight, Magnets' and Separate's and Tracks' and Mines' and
  Black Box's words, the About dialog's license names (`A-filling-1`,
  `A-magnets-1`, `A-separate-2`, `A-tracks-1`, `A-mines-1`, `A-blackbox-2`,
  `A-licensing-1`).

Reproduced and left as they are, with the requirement now saying so, each put
to the owner: `A-pattern-1`, `A-crossing-2`, `B-guess-5`, `A-bridges-2`.

Did not reproduce: `A-subsets-1`, `A-clusters-1`, `A-sixteen-1`, `A-net-1`,
the edge-line half of `A-galaxies-4`.

## What the closing check found that neither list held

Task 4.3's check was run over every requirement in this change's deltas, not
a sample of twenty: the first twenty read against the code turned up six that
the code contradicted, so the rest were read too. Thirty-one of 108 disagreed.
Most were a sentence claiming a little more than the code does, and the
requirement was corrected. Seven were defects, fixed here with a test seen to
fail first:

- Crossing: a number typed over a cell that already held its digit stalled
  there, and the next digit overwrote the cell.
- Bridges: on a board that forbids loops, red marks went stale while any loop
  stood.
- Rome: a press in the margin beside the grid placed an arrow, and Clear on an
  empty square made an undo step.
- Tracks: a track of more than 256 squares finished with no highlight and
  waited out the flash all the same.
- The gate: a documentation edit staged with a deleted or moved source file
  took the documentation-only shortcut.
- A crash report: the referrer was kept by a prefix match on the origin, the
  event ID shown could be an unlisted error's, and the words did not mention
  the settings a report carries.
- Filling: the keyboard cursor was the completed region's own hue, hard to see
  in the dark scheme.

It also added one guard, `src/engine/coord-conversion.test.ts`, over the
hand-written pixel-to-cell conversions `A-engine-helpers-1` was about.
