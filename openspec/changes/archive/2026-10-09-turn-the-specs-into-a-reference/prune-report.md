- "A style pass changes no behavior and adds no abstraction": the comment-and-naming pass it was written for looks finished. Is a further pass expected?
- "Adopting or relocating a help page changes no words, attribution or URL": the adoption of upstream's pages is done (`help/upstream/` is gone). Kept for the URL promise on any later relocation; is that promise stated elsewhere?
